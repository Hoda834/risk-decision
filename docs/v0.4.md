# Version 0.4 pilot

Install with `python -m pip install -e '.[dev]'`, then run `risk-decision-app`.
On Windows the same commands work in a terminal with the virtual environment activated.
The original batch command remains separate and uses a different scoring model.

Use New case, then Describe issue. Manual entry requires no model. Optional extraction
uses an installed Ollama executable and a model name supplied by the user. Install and
load the model separately. This release includes no model weights and no API credentials.
Only the explicit Extract button invokes the model. Configure Ollama for local inference
if the source contains private information. The application does not control the Ollama
server's deployment or retention settings.

Every suggested field requires an exact source quote. This checks provenance, not semantic
truth. A reviewer must check and may edit each statement before applying it. Missing
fields stay blank and the form displays questions. The source, original suggestions,
confirmed edits and model name are retained. No probability or severity is assigned by AI.

Complete Assessment and record a human decision. Add actions with owners and deadlines.
Completion needs evidence and a named recorder. It never changes the category. After
completion create a new assessment version, reassess the evidence, lock the version and
record the decision. Closure requires no open actions, a known observed outcome, and an
assessment made after the latest action completion. Keep the case open with a future
review date if uncertainty remains. Not observed does not establish that the underlying
risk has disappeared; record the observation window and closure rationale in the evidence.

The register identifies overdue actions, reviews due and assessments awaiting a recorded
decision. Reminders are calculated when the register opens; no emails or background jobs
are sent. Export the register as JSON. Reopening creates a new assessment version.

Back up the data directory before upgrading. Existing version 0.3 drafts remain readable;
new lifecycle and intake fields are optional. Config now lives inside
src/risk_decision/config. The former root config files are retained for reference only.

This is a local, single-operator pilot. Names and roles are declarations, not authenticated
identities. File persistence has no multi-user concurrency control. The audit hash chain
can detect internal edits but is not independently anchored and cannot prove that a tail
was not removed. It is not an access-control or tamper-proof system.

No trained predictive model, empirical AI accuracy claim, research adoption claim or JOSS
readiness claim is made. Live Ollama inference needs validation on the selected local
model. Automated adapter tests use controlled responses and do not measure model quality.
