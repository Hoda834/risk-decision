# Contributing

Describe the observed behaviour, expected behaviour and a minimal reproducible input in
an issue. Remove private case information. Propose focused changes with tests for changed
decision behaviour. Run `python -m pytest -q` before proposing a change. Policy changes
must increment policy_version and document altered decisions. The maintainer reviews
contributions; response times are not guaranteed. This project is a pilot, with no service
level commitment. AI-assisted changes should identify their scope and human checks.
